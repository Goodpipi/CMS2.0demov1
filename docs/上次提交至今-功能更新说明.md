# 上次提交至今：功能更新说明

基准提交：`6a8f4d5`（2026-09-02，《按入口补齐海报、话术、推文与长图流程，并将大纲改为只读卡片。》）  
范围：该提交之后、尚未再次提交的全部本地改动。

本文只描述**对使用者可见的变化**。判断标准：

- **功能变动**：交互、流程、信息架构、页面能力发生了变化；即使背后仍用演示数据，也算功能。
- **Mock 数据**：只是换了示例文案、示例文献、演示引用结果，交互逻辑本身没有新能力。

---

## 一、功能变动

### 1. 话题洞察入口不再显示顶部流程导航

从首页「话题洞察」进入后，中间「内容预览」只保留标题，**不再出现**「创建任务 → 话题洞察 → Brief → 文献 → 大纲 → PPT」那一行。

该入口只做话题洞察：对话欢迎语与快捷芯片收成「基于素材生成话题洞察」，不再并列「直接生成文案 / 图片 / PPT」。

其他入口（医学与推广、会议海报、更多内容等）的顶部流程条不受影响。

### 2. 病例内容、学术证据解读不再走 Brief / 文献步骤

这两个入口的流程里**不再出现 Brief、文献节点**。对话里若输入「检索文献」「生成 Brief」「查看 Brief」，会提示该入口不包含这两步。

新建时中间节点仍先留空，等用户第一步操作（如生成 PPT / 推文 / 长图大纲）后再展开对应路径。

### 3. 医学与推广：左侧素材顺序与参考文献分组

从「医学与推广内容」进入后，左侧引用素材顺序改为：

**品牌策略 → Brief → 参考知识 → 参考文献**

在该入口添加的文献会进「参考文献」，不再混进「参考知识」。

顶部流程补上 **意见收集**，现为：创建任务 → 生成话术 → 意见收集 → 提交 Veeva 审批。  
欢迎语收成「请先添加参考知识或品牌策略，再输入「生成话术」」。

会议海报流程条改为：**创建任务 → 生成主KV → 生成会议海报 → 意见收集 → 提交 Veeva 审批**（「一键手机」仍可在对话里使用，但不再作为顶部节点）。

### 4. 文献添加：四栏来源 + 全文预览

左侧「添加材料」打开文献弹窗后：

- 结果按 **CMS / DEEP / 个人知识收藏 / 外部知识库** 分成四竖栏。
- 顶部说明改为：如需检索更多文献，请访问 **CNKI、万方医学** 等三方知识库（可点击外跳）。
- 每条结果带来源标签（CMS / DEEP / 个人知识收藏 / PubMed、CNKI、万方等）。
- 可添加的文献，**点击标题可打开全文预览**，再决定是否加入当前任务。
- 打开弹窗即可看到各来源结果，不必先输入关键词；仍可用关键词缩小范围。

> 文献正文、来源标签、四栏条目是本地演示数据；四栏布局、预览、外链说明属于功能。

### 5. 参考文献超过 10 篇时的提示

左侧「参考文献」**多于 10 篇**时，分组标题下出现静态说明：

**由于模型上下文限制，系统会优先筛选关联度最高的文献**

10 篇及以内不出现。生成时不会把全部文献同等送进上下文，而是优先用关联度更高的若干篇。

### 6. 生成 PPT 后，实际被引用的文献打「已引用」

生成 PPT（或 PPT 大纲）后，左侧素材里**真正写进大纲参考文献的条目**会标绿色 **已引用**。

未被用到的文献保持原样。文献多于 10 篇时，通常只有关联度更高的那几篇会带此标签，与上一条提示一致。

### 7. 大纲参考文献精确到卷期页码，并标在对应要点上

PPT / 推文 / 长图大纲里的参考文献不再只写「期刊 + 年份」，而是带上 **卷（期）：页码**，例如：

`Lancet Diabetes Endocrinol, 2024, 12(6): 412-414.`

不同页面可以引用同一篇文献的**不同页码**。

正文要点、配图旁出现 **角标序号**（¹ ²），对应本页参考文献列表。推文 / 长图章节同样可带引用角标。

### 8. PPT 大纲改为平铺页卡片

PPT 大纲中间不再按「节」分组展示，**所有页排成一张张卡片**（封面、目录、章节标题页、正文、封底仍用页类型区分）。

章节标题页单独成卡，用于开启新一节，而不是再套一层节标题栏。

推文 / 长图大纲卡片上**去掉「章节图片」字段**；参考文献仍写在每张卡片内。

### 9. 手动编辑（原「手动调整」）

界面文案 **「手动调整」全部改为「手动编辑」**（PPT / 图片工具栏按钮、编辑页标题、海报引导语）。

PPT 手动编辑左侧去掉「页面编辑 / 添加元素」两个页签。插入行改为：

**文字 | 图片 | 添加元素**

点「添加元素」弹出素材分组（LOGO 与图标、官方图片、其他素材）。图片编辑里该弹窗还会提供形状工具。Esc 可关闭。

### 10. 首页历史任务入口标签分色

历史任务标题旁的入口标签不再共用一种蓝绿色，六种入口各用一色，便于扫一眼区分：

| 入口 | 颜色 |
| --- | --- |
| 病例内容 | 天蓝 |
| 医学与推广内容 | 绿 |
| 学术证据解读 | 藏青 `#103c8f` |
| 会议海报 | 紫 |
| 话题洞察 | 青绿 |
| 更多内容 | 琥珀 |

## 二、仅 Mock / 演示数据变化

这些不改变操作路径，只是把占位内容写得更像可追溯文献。

### 1. 大纲与文献条目的卷期页码

PPT / 推文 / 长图 mock 大纲里的参考文献，以及检索池中的期刊文献，补上了 volume / issue / pages。  
**不是真实文献库返回的元数据。**

### 2. 文献检索四栏内容

CMS、DEEP、个人知识收藏、外部知识库四栏的篇目、摘要、全文预览都是本地 mock。DEEP 标签与「证据图 / 指标速览」类标题也是演示用的。

### 3. 「已引用」对应关系

生成 PPT 后，会把大纲里的参考文献改写成当前任务里实际加入的文献（关联度高的优先）。  
标签是按大纲字符串匹配到左侧条目，**不是模型真实抽引。**

### 4. 话术欢迎语缩短

医学与推广入口的欢迎语去掉了「生成后可导出 DOCX / 提交意见收集」那一段说明，能力本身还在，只是进门文案更短。

## 四、这次没有变成「真系统」的部分

- 没有真实文献库、没有按模型上下文窗口真实截断文献。
- 「已引用」不是从生成模型的引用列表回写，而是演示大纲与左侧文献的绑定。
- 卷期页码、DEEP 标签、四栏篇目都不是外部 API。
- 话题洞察入口去掉导航后，并未新增独立的洞察产品形态（仍是原工作台预览）。
- 手动编辑弹窗里的素材仍是本地品牌元素，不是 ImageBank。

## 五、建议验收路径（按功能，不按 mock）

1. 首页点「话题洞察」→ 选产品 → 中间不应再有流程导航；对话芯片只有「基于素材生成话题洞察」。再进「医学与推广」确认流程条还在。
2. 「病例内容」「学术证据解读」：顶部不应出现 Brief / 文献；输入「检索文献」应提示该入口不含此步。
3. 「医学与推广内容」：左侧顺序为品牌策略 → Brief → 参考知识 → 参考文献；添加文献后应出现在「参考文献」。
4. 点「添加材料」：四栏来源、CNKI/万方链接、点标题能开全文预览。
5. 在推广入口往参考文献加到 11 篇：出现上下文限制提示；再输入「生成PPT」：只有部分文献带「已引用」，大纲参考文献带卷期页码，要点有角标。
6. PPT 大纲应为平铺页卡片（含章节标题页），不是按节折叠的列表。
7. 打开 PPT「手动编辑」：按钮文案是「手动编辑」；插入行为文字 / 图片 / 添加元素，点添加元素出弹窗，Esc 可关。
8. 回首页看历史任务标签：六种入口颜色互不相同。
