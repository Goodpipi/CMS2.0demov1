# 上次提交至今：功能更新说明

基准提交：`ec5d1d5`（2026-08-31，《完善内容工作台流程与 PPT 创作体验》）  
范围：该提交之后、尚未再次提交的全部本地改动。

本文只描述**对使用者可见的变化**。判断标准：

- **功能变动**：交互、流程、信息架构、页面能力发生了变化；即使背后仍用演示数据，也算功能。
- **Mock 数据**：只是换了示例文案、示例图片、演示任务内容，交互逻辑本身没有新能力。

## 一、功能变动

### 1. 首页入口进入工作台后，流程与提示按入口区分

新建任务仍要先选产品，但进入工作台后不再是同一套通用提示。六个入口各自锁定欢迎语、快捷芯片、中间「任务已创建」说明，以及后续流程节点：

| 入口 | 默认流程 | 中间提示要点 |
| --- | --- | --- |
| 病例内容 | 按用户第一步再展开（PPT / 推文 / 长图） | 请上传脱敏病例素材；若需专家点评，再上传点评示例 |
| 医学与推广内容 | 创建任务 → 生成话术 → 提交 Veeva | 先加参考知识或品牌策略，再输入「生成话术」 |
| 学术证据解读 | 按用户第一步再展开 | 请添加待解读的目标材料，也可补充其他参考知识 |
| 会议海报 | 创建任务 → 生成主KV → 生成会议海报 → 一键手机 → 提交 Veeva | 先生成主 KV，再生成海报，最后可出手机版 |
| 话题洞察 | 话题洞察及相关生成 | 请添加参考知识或品牌策略后再做洞察 |
| 更多内容 | 仍为灵活流程 | 保持原来的通用说明 |

入口类型会写入任务，用于工作台结构和历史列表标签，**不会再自动发出一句用户消息**（与上次提交一致）。

### 2. 左侧引用素材按入口换分类

顶部改为统一的 **「添加材料」**（原分类旁的分散「添加」收掉）。分类区可折叠。

| 入口 | 左侧分类 |
| --- | --- |
| 病例内容 | 病例素材 / 参考知识 / 点评示例 |
| 会议海报 | 视觉参考 / 会议信息 |
| 学术证据解读 | 目标解读材料 / 其他参考知识 |
| 话题洞察 | 参考知识 / 品牌策略 |
| 医学与推广、更多内容 | 参考知识 / 品牌策略 / Brief（与上次提交相同） |

会议海报的「会议信息」额外提供：

- **下载模板**：导出 CSV 会议信息模板；
- **上传**：把填好的会议信息文件加入该分类。

添加材料弹窗标题改为「添加材料」，检索/上传会落到当前入口对应分类，而不是一律进「参考知识」。

> 分类里预置的文件名、会议 CSV 示例行是演示数据，见下文「Mock」。分类切换、折叠、统一添加入口、会议信息下载/上传属于功能。

### 3. 会议海报固定流程

从「会议海报」进入后，顶部流程固定为：

**创建任务 → 生成主KV → 生成会议海报 → 一键手机 → 提交 Veeva 审批**

操作路径：

1. 对话输入「生成主KV」：对话区出图；点击图片或「修改主KV」，中间可用画笔圈定并导出图片。
2. 输入「生成海报」：可点选元素、手动调整；支持导出 **图片 / PPTX / PSD**，也可导入本地版本。
3. 输入「一键手机」：生成竖版海报，同样可点选、导出。
4. 未按顺序点流程节点时会提示先完成上一步（例如未生成海报就点「一键手机」）。
5. 中间已选中海报元素时，若输入的是流程指令（如「一键手机」），仍走流程，不会当成「改这个元素」的 AI 指令。

### 4. 医学与推广：生成话术

从「医学与推广内容」进入后，默认走话术而不是普通多条文案：

- 输入「生成话术」后，中间是纯文字编辑器，可直接改。
- 支持导出 **DOCX**。
- 可提交团队意见收集、提交 Veeva 审批。
- 顶部流程为：创建任务 → 生成话术 → 提交 Veeva。

### 5. 推文大纲与长图大纲

所有会用到推文/长图的入口，对话里可用：

- 「生成图文大纲」→ 中间「推文大纲」；
- 「生成长图大纲」→ 中间「长图大纲」，并选择图片模板（含空白模板）后再生成长图。

推文大纲确认后可「生成图文」进入图文预览（中间可改字、换配图、调顺序）。  
长图大纲确认后按所选模板生成长图，中间可点选元素或手动调整，并导出图片 / PPTX。

对应流程节点：

- 推文：推文大纲 → 图文 → 提交 Veeva；
- 长图：长图大纲 → 长图 → 提交 Veeva。

### 6. PPT / 推文 / 长图大纲改为「一页一张卡片」

三类大纲的页面（或章节）都改成卡片：

- **卡片内是只读纯文本**，不能在卡片里直接改字。字段结构与改前一致：
  - PPT：标题、核心内容、可视化建议、**当前页面参考文献**；
  - 推文 / 长图：标题、核心信息、章节图片、章节 TMSH，以及 **本章参考文献**。
- 推文、长图的参考文献从「整份大纲最底部一堆」改为 **写进每张卡片**，与 PPT 一致。
- 支持 **拖拽调整卡片顺序**（PPT 封面/目录/封底仍不可拖，与改前相同）。
- 卡片右上角新增 **「修改本页」**：弹出「请告知AI您想如何修改本页大纲」，下方输入框，确定后该页内容更新。
- 章节折叠、添加节/页、重新生成大纲、选择模板、底部生成按钮都还在。
- 推文/长图顶部的整体标题仍可改；PPT 节名称仍在节标题栏改（这些不在页面卡片内）。

### 7. 历史任务显示入口标签

首页历史任务、审阅端历史列表，每条任务标题旁增加入口标签（病例内容、医学与推广内容、学术证据解读、会议海报、话题洞察、更多内容）。搜索也会匹配该标签。

### 8. 其它界面与提示收敛

- 生成服务失败时，不再出现「请检查 DEEPSEEK_API_KEY」一类技术提示，改为「生成服务暂时不可用，请稍后重试」。
- 演示模式下的对话占位，不再写「演示模式 / DeepSeek 恢复后…」，改为直接说明可以生成哪些内容。

## 二、仅 Mock / 演示数据变化

这些不改变操作路径，只是把占位内容换成更接近演示场景的示例。

### 1. 会议海报视觉

- 主 KV 改为深红底、发光肾脏、CKD 标题，与红色会议海报同一套风格（不再是蓝绿心内科示意）。
- 会议海报、手机竖版为同一主题的 SVG 示意（CKD 患者肾脏保护新进展研讨会）。
- KV / 海报各有初稿、强化标题等小版本快照，供鱼眼轴演示切换。

**没有接真实设计稿生成。** 对话里点「生成主KV / 生成海报 / 一键手机」是套用上述示意。

### 2. 推文 / 长图大纲与图文

- 推文、长图大纲共用一套 CKD 合并代谢风险病例的五章结构（患者概况、关键指标、临床解读、管理思路、专家点评）。
- 每章自带配图路径、TMSH 和 1–2 条参考文献；整份大纲仍保留一份文献总表供内部使用。
- 「生成图文」后的富文本正文是同一病例的演示 HTML，不是模型实时写作。

### 3. 话术总结正文

「生成话术」写出的是围绕当前所选产品（如优思明）的科室拜访话术总结：开场、核心信息、沟通结构、FAQ、合规提醒。  
**不是真实拜访记录，也不会按上传材料实时改写。**

### 4. 「修改本页」确定后的结果

大纲卡片点「修改本页」并确定后，该页标题会加上「（已修订）」，并追加一条「【AI 修订】已按「…」调整…」说明。  
这是前端写死的演示更新，**没有调用模型重写该页。**

### 5. 引用素材里新增的示例文件

为新分类预置了演示条目，例如：

- 病例素材：CKD 合并代谢风险患者病例资料；
- 点评示例：肾内科病例专家点评示例；
- 视觉参考：CONFIDENCE 周周谈、Radimetrics 海报图；
- 目标解读材料：KDIGO 指南节选、FIDELIO-DKD 数据摘要。

会议信息 CSV 模板里预填了一行「CKD患者肾脏保护新进展研讨会」示例，需要使用者自行替换。

### 6. 历史任务演示会话的入口标签

内置演示任务分别标成医学与推广 / 学术证据解读 / 会议海报，便于首页列表看出标签样式。任务内容本身仍是原来的演示会话。

### 7. 长图图片模板

长图大纲下方推荐模板：第一个为空白模板，其余仍是已有的三张海报实拍（Radimetrics、CONFIDENCE 周周谈、房颤卒中预防）。按模板生成长图时，非空白模板会套用对应预览图做头图。

## 四、这次没有变成「真系统」的部分

- 会议海报 / 主 KV / 手机版没有真实出图模型，导出的 PSD/PPTX 是当前画面的演示封装。
- 话术、推文大纲、长图大纲、图文成品没有按上传病例/文献实时生成。
- 「修改本页」没有真正把指令送给模型。
- 会议信息模板下载/上传只进入本地引用列表，不会写入真实会议主数据。
- 入口标签、产品、材料分类目前用于演示引导，不会写入独立业务库。

## 五、建议验收路径（按功能，不按 mock）

1. 登录 → 首页点「病例内容」→ 选产品 → 左侧应是病例素材 / 参考知识 / 点评示例；对话欢迎语提到脱敏病例与点评示例。输入「生成PPT大纲」：中间是只读卡片，可拖拽内容页，点「修改本页」弹出指定文案的输入框，确定后该页出现修订痕迹。
2. 同一任务再输入「生成图文大纲」：卡片内有核心信息、配图、TMSH 和本页文献，底部不再单独堆文献；「生成长图大纲」同理，且下方能选图片模板（含空白模板）。
3. 回首页点「医学与推广内容」→ 选产品 → 流程为生成话术；输入「生成话术」后中间可改字、导出 DOCX。
4. 回首页点「会议海报」→ 选产品 → 按「生成主KV」→「生成海报」→「一键手机」走完；未生成时点流程节点应有提示；海报可选元素并看到导出图片/PPTX/PSD；会议信息可下载模板并上传。
5. 回首页点「学术证据解读」：左侧是目标解读材料 / 其他参考知识。
6. 回首页看历史任务标题旁是否有入口标签；审阅账号首页列表同样有标签。
7. 在海报已选中元素时输入「一键手机」，应出手机版，而不是拿选中元素去做局部修改。
