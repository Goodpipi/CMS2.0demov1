# 上次上传至今：功能更新说明

基准提交：`32e7cad`（2026-08-27，《去掉大纲冗余章节标题与素材库删除，并修复 Brief 底部裁切。》）  
范围：该提交之后、尚未再次推送的全部本地改动。

本文只描述**对使用者可见的变化**。判断标准：

- **功能变动**：交互、流程、信息架构、页面能力发生了变化；即使背后仍用演示数据，也算功能。
- **Mock 数据**：只是换了示例账号、示例产品、示例图片/模板、演示任务文案，交互逻辑本身没有新能力。

---

## 一、功能变动

### 1. 账号与身份

- 增加登录页：进入工作台前需选择账号。
- 工号改为 **CWID**（五位字母），个人信息菜单展示姓名、部门、职位、邮箱、CWID、Token 用量。
- 首页右上角、工作台右上角均可打开个人信息，并支持登出。
- **首页、工作台不再提供品牌切换**；品牌切换只保留在「个人知识收藏」「视觉素材库」页内，用于筛选素材。

> 账号内容本身是演示账号，见下文「Mock」。登录、菜单、CWID 展示、品牌切换位置调整属于功能。

### 2. 新建任务流程

- 从首页入口新建任务时，**先选择本任务对应的产品**（女性健康商品名列表），再进入工作台。
- **不再根据入口自动发送一句话**（例如不会再自动出现「生成病例内容」用户消息）。入口类型仍会记住，用于后续流程引导。
- 新建后中间「任务已创建」卡片改为操作提示：可先上传品牌策略/参考文献做话题洞察，或上传 Brief 走 PPT 从零到一；并保留 **打开本地文件**、**打开 CMS 文件**。
- 首页入口分类与文案：
  - 「病例内容 / 医学与推广内容 / 学术证据解读」卡片的详细描述改为 **二级场景标签**。
  - 「会议海报 / 话题洞察 / 更多内容」仍用原来的说明文字。
  - 对话里若提到这些二级场景名称，会被识别为场景（如「医学PPT-HCP」「指南解读」）。

二级场景一览：

| 一级入口 | 二级场景 |
| --- | --- |
| 医学与推广内容 | 医学PPT-HCP、医学推文-HCP、医学内容一图读懂-HCP、市场推广PPT、医学PPT-患者、医学推文-患者、医学内容一图读懂-患者、内部培训PPT、内部培训一图读懂、话术总结 |
| 病例内容 | 病例PPT、病例推文、病例卡 |
| 学术证据解读 | 指南解读、文献解读、研究解读、共识解读 |

### 3. 知识库与素材引用

- **去掉专业术语库**入口与相关导入/新增能力。
- 「参考知识库」更名为 **个人知识收藏**；去掉「设置默认知识」相关能力。
- 左侧引用素材：
  - 去掉「默认素材」分类；
  - 去掉模板、品牌元素入口；
  - 添加文献改为独立检索弹窗（见下）。
- 个人知识收藏、视觉素材库支持按品牌筛选（通用素材始终可见）。

### 4. 文献检索

- 引用素材中添加文献，改为独立弹窗：先选检索范围，再输入关键词。
- **未输入关键词时不展示结果**；输入后才检索（例如输入「医学」）。
- 来源展示为可点击的蓝色下划线链接（如 CNKI、万方医学）。
- 「检索文献」操作放在文献卡片第一行右上角。
- 一次展示 30 条，滚到底可点「查看更多文献」再加载 30 条。

> 文献条目本身是本地演示数据；检索交互、空查询、分页、外链展示属于功能。

### 5. 工作台流程导航

- 洞察、Brief、文献、大纲、PPT 等状态改为顶部 **流程式导航**。
- 去掉「可跳过」字样。
- 刚新建任务时，除「创建任务」和最后的「提交 Veeva」外，中间节点先留空；**根据用户第一步操作再决定后续路径**。

### 6. PPT 制作与版本

- 大纲页推荐内置模板，并支持「更多模板」弹窗挑选。
- 「导入本地版本」右侧增加 **切换 PPT 模板**。
- 去掉单独的「查看历史版本」按钮；大版本与小版本都在预览下方的 **鱼眼时间轴** 上查看和切换。
- 回溯按钮文案统一为 **「回溯到该版本」**，不再出现「丢掉小版本」之类措辞。
- 生成 PPT 后，会重新写入该页的小版本轴和「当前版本任务」（演示任务列表）。此前新建任务会清掉旧 mock，生成路径又没补回来，导致轴和任务列表空空的。

> 小版本 / 任务条目的具体文案和页预览是演示数据；鱼眼切换、回溯、生成后自动出现版本轴，属于功能（演示环境下的功能）。

### 7. 手动调整（页面编辑）

- PPT 手动调整中，「视觉编辑」改为 **页面编辑**。
- 增加 **「添加元素」**：可插入 LOGO 与图标、官方图片、其他素材。
- 支持修改字体（字体下拉）。
- 插入能力从「插入文字」扩展为「插入」，并支持插入图片。

### 8. 视觉素材库

- 去掉富文本模板分类，只保留 PPT 模板、图片模板、品牌元素。
- 品牌元素的分类与条目与手动调整「添加元素」对齐：**LOGO与图标 / 官方图片 / 其他素材**。
- 图片模板、PPT 模板的挑选与生成会套用库中的版式预览图。

### 9. 历史任务

- 首页历史任务列表增加标签切换（如历史任务 / 意见收集任务）。

### 10. 其它界面收敛

- 去掉部分提示胶囊（过期/即将过期一类的粗胶囊提示）。
- 文献卡片上的检索操作位置、链接样式按上述规则调整。

## 五、建议验收路径（按功能，不按 mock）

1. 登录 → 看 CWID 与个人信息 → 确认首页/工作台没有品牌切换。
2. 点「病例内容」新建 → 选产品 → 对话里**没有**自动用户句 → 中间卡片是新提示 + 两个打开按钮。
3. 看首页三张有二级场景的卡片是否展示标签；会议海报等是否仍是原说明。
4. 个人知识收藏 / 视觉素材库：切换品牌、确认无富文本模板、品牌元素三类与「添加元素」一致。
5. 引用素材添加文献：空搜无结果 → 搜「医学」→ 30 条 → 查看更多 → 来源为蓝链。
6. 生成 PPT：鱼眼轴出现小版本，「当前版本任务」有数据；回溯文案为「回溯到该版本」。
7. 页面编辑 → 添加元素、改字体；大纲页切换 PPT 模板。
8. 流程导航：新建时中间为空，先做洞察或先做 PPT，后续节点随之展开。
